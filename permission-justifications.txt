CHROME WEB STORE – PRIVACY PRACTICES TAB

=== Single purpose ===

Sound Tools applies real-time audio effects (distortion, reverb, filters) to the audio and video playing in web pages, and lets the user control these effects with the popup or with a MIDI controller.

=== storage ===

Sound Tools uses chrome.storage.local to save the user's audio effect settings (distortion amount, reverb room size and mix, filter frequencies and resonance) and their MIDI controller mappings, so they are remembered across tabs, page reloads and browser sessions. Only these settings are stored, locally on the user's device. No personal data is collected or transmitted.

=== Host permission (<all_urls>) ===

Audio and video can play on any website, so Sound Tools runs a content script on all pages to be able to route the page's <audio>/<video> elements through its effects when the user asks for it. The script stays idle until the user enables an effect from the popup (or from a MIDI control they linked): it doesn't read or modify page content, and it never sends any data anywhere. A specific list of sites can't be used because users choose which site they want to process.

=== Remote code ===

No, I am not using remote code. All JavaScript is bundled in the extension package.

=== Data usage ===
